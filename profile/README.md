# LLM Frameworks

Open-source, model-agnostic governance architecture for AI-assisted reasoning.

**Core = Reason, Truth, Governance.**

An impersonal logic library. No author names, no credit lines, no personal data.

## Authority model

The AI proposes. The steward disposes.

- Every claim carries an epistemic tag.
- Every tag requires a receipt (source + warrant).
- Opposing views must be steel-manned.
- Contradictions go in a ledger instead of being hidden.
- Nothing changes without the steward's ruling.

The steward is whoever holds the pen — the role, not a person.

## Layers

| Layer | Purpose |
|-------|---------|
| **Core** | Reason, Truth, Governance — the logic library |
| **Applications** | Things built on the Core |
| **Reference** | Evaluated knowledge — "remember, not know" |
